# Vendored Fonts

`material-symbols-rounded-latin-wght-normal.woff2` is the full Material Symbols Rounded
variable font file that was previously provided by `@fontsource-variable/material-symbols-rounded`.
It is vendored here so icon rendering keeps the same metrics without requiring an icon-font npm
package.

Downloaded from:

`https://cdn.jsdelivr.net/fontsource/fonts/material-symbols-rounded:vf@5.3.0/latin-wght-normal.woff2`
